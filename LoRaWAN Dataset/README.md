# LoRaWAN SIEM Evaluation Dataset
 
Log data exported from Graylog, collected during a LoRaWAN network security evaluation using Graylog as the SIEM. The dataset contains normal background traffic and logs from the following attack scenarios:
 
- Gateway SSH brute-force
- Network server SSH brute-force
- MQTT unauthorized publish
- Exact MQTT replay
- MQTT flood
- Modified MQTT replay and metadata manipulation
